## 1. 요약

이번 세션에서는 `cursor-tdd-cart` 프로젝트에 대해 Cursor Rules 생성, Context7·GitHub MCP 활용, TODO 스택 검토, GitHub 업로드 및 이슈 등록까지 수행했다. 핵심은 **AGENTS.md(지도) + `.cursor/rules/*.mdc`(실행 규칙)** 구조를 확립하고, **GitHub MCP `push_files`**로 로컬 작업물을 원격 `main`에 반영한 것이다.

주요 흐름:
1. Cursor Rules 생성 방법 조사 및 프로젝트 맞춤 Rules 3종 작성
2. `c2c-work-rules.mdc`로 항상 적용 규칙 확정 (중복 `tdd-workflow.mdc` 제거)
3. Context7 MCP로 pytest·Flask 문서 조회
4. GitHub MCP로 저장소 목록 조회 → `push_files` 업로드 → 이슈 #1 생성
